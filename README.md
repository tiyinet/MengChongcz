## 它是什么

「萌宠出征」是一款治愈系宠物割草游戏（survivor-like / bullet heaven 类型）。核心循环只有两件事：

- **按住鼠标或 WASD** —— 带宠物走位，躲开虫群
- **回到主人身边贴贴** —— 攒能量，能量满了双击放合击

其余全自动：宠物自己攻击、自己升级、自己拾取三选一强化。手机上的割草游戏要一直点，这个不用——一只手上鼠标，一只手上咖啡。

### 开箱即玩

- 双击图标就进游戏，没有网页、没有登录框、没有广告弹窗
- 本地存档，进度、战绩、解锁的宠物都存在你自己电脑上
- 通关 5 关后，可以把毛孩子请到桌面上陪你办公（桌面宠物模式）
- 老板键 `Ctrl+Alt+X` 一键隐藏整个游戏，再按一次恢复

### 零压力

不逼氪、无抽卡、无体力限制。没有「明天再来」，也没有「体力不足」。

## 核心玩法

### 关卡与模式

- 主线 **40 关**，四大世界：篱笆小径(1-10) → 小区花园(11-20) → 温馨客厅(21-30) → 深夜厨房(31-40)，每个世界第 10 关是 Boss
- 通关第 12 关解锁**无尽模式**：虫潮不断，冲本机击杀榜
- 镜头固定、地图比屏幕大，敌人从房间三面压进来
- 开局镜头从地图全景推向你的毛孩子，先看清战场再开战

### 主人守望系统

主人钉在每关地板的固定位置守家，不再跟着你满场跑。他站在家门口，会呼吸、会重心换脚，身体一直面向你。你跑得太远，他会抬手招你「回来呀」。遮挡关系按实际位置正确显示，不会出现「主人被宠物盖住」。

### 16 个品种

| 类别 | 品种 |
| --- | --- |
| 猫 | 橘猫、布偶、黑猫、蓝猫 |
| 狗 | 奶狗、金毛、柯基、德牧 |
| 鸟 | 虎皮、玄凤、牡丹、信鸽 |
| 龟 | 巴西红耳、草龟、花龟、地图龟 |

- 初始 4 只出战，此后每累计通关 2 关按图鉴顺序解锁 1 只
- 每只宠物有本命技能（冲刺 / 暖阳 / 起飞 / 咆哮 / 鸣叫等），满级 + 匹配玩具可触发进化（风暴飞盘 / 极光射线 / 混沌毛线球 / 梦幻泡泡机）
- 毛色、性格、性别、声线全部可自定义（纯外观，不影响战斗数值）
- 主人形象二选一：女主人 / 男主人，战斗立像与迎接演出随选择变化

## 桌面宠物模式

通关 5 关解锁。在「我的萌宠」里点「把这只放上桌面」，毛孩子当场站到桌面角落。

- 平时安静守着：鼠标不动它就站定呼吸，鼠标活动它才散步、做动作
- 拖拽 = 放任意位置；双击 = 打开出征大厅；撞屏幕边缘自动掉头
- 每个品种的走路朝向按实拍素材逐一校准，黑猫、柯基不再倒着走
- 右键菜单含投喂、抚摸、陪玩、抱抱、吃饭、睡觉、招呼、散步、安静、摸鱼伪装、叫声开关
- 猫狗鸟龟各有专属叫声与台词

- **每日任务与家园币**：签到 +20、任务每条 +15、昨夜冒险礼物 30-80，只用于买装饰，不进战斗

- **定制萌宠（即将上线）**：上传你家毛孩子的照片，生成专属形象入住游戏

## 安装

1. 下载 `MengChongcz_Setup.zip` 并解压，**不要直接在压缩包里双击运行**
2. 双击 `MengChongcz_Setup_1.0.28.exe`
3. 如果 Windows 弹出蓝色提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。这是安装包暂未购买代码签名证书时的常规提示，不是病毒；本软件不捆绑任何第三方软件
4. 旧版用户可直接覆盖安装，老存档自动兼容，宠物数据、通关进度、图鉴成就都不丢
5. 装完桌面和开始菜单出现「萌宠出征」图标，双击即玩。进程名 `MengChongcz.exe`

## 常见问题

**首次打开弹蓝色警告？**
点「更多信息 → 仍要运行」，属未签名软件的正常提示。

**双击安装包没反应 / 提示已损坏？**
右键安装包 → 属性 → 勾选「解除锁定」后再双击。

**桌面上的宠物没出现？**
先通关满 5 关解锁桌面模式，再在「我的宠物」点「放上桌面」，当场就会站上去。

**战斗里字或图发虚？**
建议 1080p 及以上分辨率全屏玩，游戏已按物理像素渲染适配高分屏。

**想临时藏起游戏？**
`Ctrl+Alt+X` 老板键一键隐藏；桌面宠物右键「摸鱼伪装」也行。

**想卸载？**
Windows「设置 → 应用」找到「萌宠出征」卸载，存档不会被删。
