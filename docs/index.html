01它是什么

一款把「桌面宠物」和「割草游戏」缝在一起的 Windows 小游戏。核心循环只有两件事，但够你玩上几十个小时。

按住鼠标或 WASD 走位

带宠物躲开虫群，攻击是自动的。你只需要判断往哪走、什么时候收手。

回到主人身边贴贴

攒满能量就能放合击。这一招是翻盘用的，攒早了浪费，攒晚了就没机会了。

通关 5 关，它住进桌面

解锁桌面宠物模式后，游戏窗口可以缩到桌面常驻。它会自己走动、打哈欠、追你的鼠标。

05常见问题

萌宠出征是什么类型的游戏？

Windows 桌面宠物割草游戏，也就是 survivor-like / bullet heaven 这一类。你养一只宠物，带它上阵，靠走位躲开源源不断的虫群，一路打到第 40 关。通关 5 关之后可以解锁桌面宠物模式，宠物会常驻在 Windows 桌面上。

收费吗？有内购和广告吗？

完全免费。没有内购、没有抽卡、没有广告，不需要注册账号，也不需要联网。下载解压就能玩。

支持哪些系统？老电脑能跑吗？

Windows 10 和 Windows 11 的 64 位系统。安装包约 46 MB，对显卡没有特殊要求，核显就够，几年前的老笔记本也能流畅跑。

安装时提示「Windows 已保护你的电脑」怎么办？

因为没有购买数字签名证书，这是常见提示，不代表文件有问题。点「更多信息」再点「仍要运行」就行。不放心的话，用 PowerShell 跑 certutil -hashfile "MengChongcz_Setup.zip" SHA256，结果和官网上公布的一致就没问题。

桌面宠物模式怎么开？

通关第 5 关自动解锁。之后在设置里可以把游戏窗口缩成桌面常驻模式，宠物会在桌面上自己走动、打哈欠、追鼠标，点它会有反应。

存档在哪？换电脑会丢吗？

存在游戏目录下的 save 文件夹，不写系统注册表。整个文件夹拷走就能带走进度，换电脑不丢档。

和「萌宠乐园」是同一个东西吗？

不是。萌宠乐园是更早的一款桌宠养成软件，萌宠出征是芽朵软件推出的独立游戏，核心玩法是割草战斗加宠物养成，两者是同一个团队的不同作品。

有手机版吗？

目前只有 Windows 版本，Mac 和手机版还没有排期。
